# Clear AppUI Lab

Run `flutter run -d macos` to open the complete widget gallery and the course
interaction demo. Select “完整元件庫” for all 39 component families. Search by
name and inspect light/dark, 2× text, RTL and long-content configurations.

For isolated browser previews, run `bash scripts/dev/preview.sh` from the
repository root. See [the development guide](../doc/app_ui/DEVELOPMENT.md) for
CPU limits, SDK setup, preview configurations and validation commands.
The [component QA record](../doc/app_ui/COMPONENT_QA.md) maps each family to its
source files, checks and fixes.
